# EnterpriseOS

EnterpriseOS is a Digital CEO operating system. It is not a chatbot, agent swarm,
workflow engine, or hardcoded company simulator.

The CEO is the only permanent intelligent entity. The Founder/Owner always has
authority above the CEO, and the CEO must request approval before financial,
privacy sensitive, legal, destructive, or irreversible actions.

Milestone 01 establishes the CEO foundation:

- startup from `main.py`
- external configuration loading
- immutable constitution loading
- owner profile loading
- company state loading
- runtime memory loading and saving
- permanent CEO runtime loop
- structured action logging
- recoverable runtime error handling

No employees, departments, workflows, project execution, model calls, tool usage,
research, thinking, or decision making are implemented in this milestone.

Milestone 02 adds the CEO cognitive engine:

- structured thought records
- deterministic executive reasoning
- explicit domain serialization for thought logging
- internal objective generation
- opportunity analysis
- extensible risk analysis
- explained executive decision records
- post-cycle reflection
- runtime-only learning notes
- dedicated thought logging in `logs/ceo_thoughts.log`

The CEO still does not execute work, use external systems, create company
structure, call models, perform research, or evolve long-term memory.
